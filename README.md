# TBS — Claude Code Workspace

The version-controlled operating logic for Trepti's BrandBoost Solutions: rules, workflows, experiments and QA. Business knowledge and client records stay in Notion. See `CLAUDE.md` for the rules and the source-of-truth map.

| Path | Contents |
|---|---|
| `CLAUDE.md` | Operating rules loaded by every Claude Code session |
| `audit/` | The TBS AI Operating System Audit (Phase 1) |
| `experiments/` | One folder per experiment: brief, record, evaluation |
| `experiments/EXPERIMENT_LOG.md` | Index of experiments and their outcomes |
| `workflows/` | Specs for workflows that have been validated or are awaiting validation |
| `outputs/` | Working outputs that contain client data. Git-ignored and never committed. |
